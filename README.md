# مغامرة الرياضيات للصف الخامس

تطبيق تعليمي تفاعلي باللغة العربية لطلاب الصف الخامس الابتدائي. النسخة المنشورة هي صفحة `index.html` مستقلة تعمل مباشرة على GitHub Pages دون إطار عمل أو حزم أو خطوة بناء.

🔗 **المستودع:** [halimfaroug/Math5-Expert](https://github.com/halimfaroug/Math5-Expert)

## المزايا

- تحدٍّ سريع مولّد عشوائيًا في ستة مسارات مطابقة لمنهج الرياضيات السعودي للصف الخامس، الجزء الأول.
- مسارات القيمة المنزلية، والجمع والطرح، والضرب، والقسمة، والعبارات الجبرية والمعادلات، والكسور الاعتيادية.
- إجابة فورية وتلميحات وتشجيع عند المحاولة، مع سلسلة انتصارات ونقاط ومستويات.
- خريطة منهج توضّح موضوعات الفصول والدروس المستهدفة.
- بطاقات مراجعة دافئة تلخّص أفكارًا مهمة في ثوانٍ.
- رسوم CSS متحركة، نجوم احتفالية، وتصميم كريمي دافئ ممتع للممارسة.
- لوحة تقدم تعرض النقاط، والدقة، وسلسلة الانتصارات، والمستوى.
- تصميم عربي باتجاه من اليمين إلى اليسار.
- ألوان دافئة وحركات بسيطة مع دعم تفضيل تقليل الحركة.
- حفظ التقدّم محليًا في المتصفح باستخدام `localStorage`.
- التطبيق مستقل في ملف HTML واحد ولا يحتاج إلى إطار عمل أو خطوة بناء أو اتصال خارجي.
- يعمل على GitHub Pages مباشرة، مع دعم الشاشات الصغيرة وتقليل الحركة.

| الفصل | الموضوعات |

| 1 | القيمة المنزلية، الأعداد الكبيرة، الكسور العشرية والمقارنة |

تمت مواءمة خريطة المنهج والتدريبات مع الملف المرفق **رياضيات الصف الخامس الابتدائي، الجزء الأول، ١٤٤٦هـ** الصادر عن المركز الوطني للمناهج. وتشمل التدريبات التقدير، القيمة المنزلية، أنماط الضرب والقسمة، تفسير الباقي، العبارات الجبرية، جداول الدوال، ترتيب العمليات، والكسور غير الفعلية والأعداد الكسرية.

## التشغيل محليًا

لا يحتاج التطبيق إلى تثبيت حزم. الملف الأساسي المنشور هو:

```text
index.html
```

ولتشغيله عبر خادم محلي، استخدم Python:

```bash
python3 -m http.server 8000
```

ثم افتح:

```text
http://localhost:8000/index.html
```

استخدام خادم محلي يُفضّل عند اختبار سلوك المتصفح أو التخزين المحلي.

## طريقة الاستخدام

1. افتح الصفحة الرئيسية واضغط **ابدأ تحدّي اليوم**.
2. اختر موضوعًا من أزرار التحدّي السريع.
3. اكتب الإجابة ثم اضغط **تحقق**.
4. استخدم التلميح عند الحاجة، ثم انتقل إلى سؤال جديد.
5. راقب النقاط والدقة وسلسلة الانتصارات.
6. استخدم قسم **محطة المراجعة الدافئة** للمراجعة السريعة.

## التخزين والخصوصية

يُحفظ التقدّم على الجهاز نفسه داخل `localStorage` في المتصفح. لا يحتوي التطبيق على خادم خلفي أو قاعدة بيانات، ولذلك قد يختفي التقدّم عند مسح بيانات الموقع أو استخدام جهاز ومتصفح مختلف.

يمكن استخدام زر **تصفير التقدّم** لمسح النقاط والشارات وسجل الإتقان من الجهاز الحالي.

## المساهمة

1. أنشئ فرعًا جديدًا من `main`.

3. اختبر الصفحة في متصفح حديث.
