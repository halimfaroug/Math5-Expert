# مغامرة الرياضيات للصف الخامس

تطبيق تعليمي تفاعلي باللغة العربية لطلاب الصف الخامس الابتدائي. يقدّم أنشطة قصيرة تعتمد على السحب والبناء والتجريب، مع مختبر مفتوح للتعلّم الحر ولوحة متابعة لحفظ التقدّم على الجهاز.

🔗 **المستودع:** [halimfaroug/Math5-Expert](https://github.com/halimfaroug/Math5-Expert)

## المزايا

- ستة فصول تغطي موضوعات الرياضيات الأساسية للصف الخامس.
- أنشطة تفاعلية في القيمة المنزلية، والجمع والطرح، والضرب، والقسمة، والمعادلات، والكسور.
- اختبارات وتمارين إضافية قصيرة مع إجابات قابلة للكشف.
- لوحة متابعة تعرض النقاط، والدقة، ودقائق التعلّم، ومستوى الإتقان.
- نظام شارات وتحفيز مبني على التقدّم.
- مختبر تفاعلي لتجربة القيمة المنزلية والكسور والمساحة وخط الأعداد والمعادلات.
- تصميم عربي باتجاه من اليمين إلى اليسار.
- ألوان دافئة وحركات بسيطة مع دعم تفضيل تقليل الحركة.
- حفظ التقدّم محليًا في المتصفح باستخدام `localStorage`.
- التطبيق مستقل في ملف HTML واحد ولا يحتاج إلى إطار عمل أو خطوة بناء.

## موضوعات الفصول

| الفصل | الموضوعات |
|---|---|
| 1 | القيمة المنزلية، الأعداد الكبيرة، الكسور العشرية والمقارنة |
| 2 | التقريب والتقدير، الجمع والطرح، والمسائل اللفظية |
| 3 | أنماط الضرب، نموذج المساحة، وخاصية التوزيع |
| 4 | نماذج القسمة، القسمة المطولة، وتفسير الباقي |
| 5 | المتغيرات، آلات الدوال، ترتيب العمليات، والميزان |
| 6 | الكسور غير الفعلية، الأعداد الكسرية، ومقارنة الكسور |

## التشغيل محليًا

لا يحتاج التطبيق إلى تثبيت حزم. يمكن فتح الملف مباشرة في المتصفح:

```text
مغامرة الرياضيات - نسخة مستقلة.html
```

ولتشغيله عبر خادم محلي، استخدم Python:

```bash
python3 -m http.server 8000
```

ثم افتح:

```text
http://localhost:8000/مغامرة%20الرياضيات%20-%20نسخة%20مستقلة.html
```

استخدام خادم محلي يُفضّل عند اختبار سلوك المتصفح أو التخزين المحلي.

## طريقة الاستخدام

1. افتح الصفحة الرئيسية.
2. اختر أحد الفصول الستة.
3. ابدأ نشاطًا من المستوى المناسب لك.
4. جرّب الحل قبل الضغط على التحقق.
5. استخدم المختبر لتجربة المفاهيم بصريًا.
6. راجع النقاط والشارات ونسبة الإتقان من لوحة المتابعة.
7. استخدم قسم **محطة التمارين الجديدة** لمراجعة اختبارات إضافية سريعة.

## التخزين والخصوصية

يُحفظ التقدّم على الجهاز نفسه داخل `localStorage` في المتصفح. لا يحتوي التطبيق على خادم خلفي أو قاعدة بيانات، ولذلك قد يختفي التقدّم عند مسح بيانات الموقع أو استخدام جهاز ومتصفح مختلف.

يمكن استخدام زر **تصفير التقدّم** لمسح النقاط والشارات وسجل الإتقان من الجهاز الحالي.

لإضافة نشاط أو تحسين تجربة التعلّم:

1. أنشئ فرعًا جديدًا من `main`.
2. عدّل الملف مع الحفاظ على اتجاه RTL ودعم الشاشات الصغيرة.
3. اختبر الصفحة في متصفح حديث.
4. تحقق من عدم وجود أخطاء تنسيق أو كسر في الحزمة.
5. افتح Pull Request يشرح التغيير وأي طريقة اختبار مستخدمة.

## English summary

**Math5-Expert** is a self-contained Arabic RTL interactive mathematics learning app for fifth-grade students. It includes six learning chapters, interactive activities, a free-form lab, progress tracking, badges, and warm animated practice cards. Open the standalone HTML file directly in a modern browser; no build step or package installation is required.
