# منصة مدارس بن الهيثم الخاصة بالرهد أبو دكنة

منصة عربية تفاعلية لمراجعة **رياضيات الصف الثاني الثانوي**، مبنية كصفحة ثابتة قابلة للنشر على GitHub Pages ومتوافقة مع بنية Vermeil الحالية في المستودع.

## المزايا

- خريطة كاملة لوحدات كتاب الرياضيات الثماني: الدوال الأسية واللوغاريتمية، الهندسة التحليلية، المتباينات والبرمجة الخطية، الإحصاء، حساب المثلثات، التحويلات الهندسية، الأعداد المركبة، والمتتاليات.
- بنك أسئلة عربي منظم حسب الوحدة والموضوع، مع إظهار الإجابة والفكرة الرياضية.
- اختبار قصير عشوائي من خمس مسائل.
- لوحة شخصية محلية لحفظ الاسم، الأسئلة المحلولة، الدقة، النقاط، والتقدم في كل وحدة.
- نظام رموز إنجاز يفتح رموز الوحدات عند إتقانها، ورمز التحدي عند إكمال الاختبار.
- PWA قابلة للتثبيت والعمل دون اتصال بعد الزيارة الأولى.
- تصميم RTL متجاوب مع الهاتف والكمبيوتر، مع استخدام شعار المدرسة المرفق في الهوية ومكان واضح لاستبداله أو تحديثه لاحقًا.

## النشر على GitHub Pages

فعّل GitHub Pages من إعدادات المستودع، واختر الفرع الرئيسي ومجلد الجذر. الملفات الأساسية (`index.html`, `manifest.webmanifest`, `sw.js`, `.nojekyll`, `logo.jpg`) موجودة في الجذر، والروابط النسبية تعمل على النطاق الجذري أو مسار المستودع.

## مصدر المحتوى

المفاهيم والقوانين والأسئلة التعليمية داخل المنصة مبنية على موضوعات وأهداف كتاب **الرياضيات — الصف الثاني الثانوي** الصادر عن المركز القومي للمناهج والبحث التربوي بخت الرضا، دون إضافة مصادر تعليمية خارجية للأسئلة والأجوبة.

## التشغيل المحلي

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000/`. التقدم محفوظ محليًا داخل `localStorage` ولا يحتاج إلى خادم خلفي.

## الملفات المهمة

- `index.html`: الواجهة والتنسيقات والمنطق التفاعلي.
- `manifest.webmanifest`: إعدادات التثبيت كتطبيق.
- `sw.js`: التخزين المؤقت والعمل دون اتصال.
- `logo.jpg`: شعار مجموعة مدارس بن الهيثم المرفق.
- `.nojekyll`: تعطيل معالجة Jekyll في GitHub Pages.

الملفات القديمة محفوظة بصيغتي `index.legacy.html`, `sw.legacy.js`, و`README.legacy.md` للرجوع إليها عند الحاجة.
