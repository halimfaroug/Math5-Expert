# Math5 Expert

A comprehensive educational application for 5th-grade mathematics learning, enriched with design patterns from the official Saudi Arabian Ministry of Education textbook.

## Overview

Math5 Expert is designed to provide an engaging, pedagogically sound learning experience for elementary mathematics students. The application combines interactive content delivery with a professional design system optimized for educational contexts.

## Design System

The Math5 Expert design system provides a comprehensive foundation for educational UI development:

### Visual Identity
- **Primary Colors**: Teal (#1E9AB0) for headers, Dark Blue (#0051BA) for sections, Brand Red (#C41E3A) for emphasis
- **Educational Colors**: Green for vocabulary, Yellow for highlights, Blue for examples
- **Typography**: Optimized for learning progression with dedicated styles for chapter titles and educational hierarchy
- **Components**: Chapter headers, concept boxes, example sections, vocabulary callouts, and problem sections

### Design Principles
- **Clarity**: High-contrast typography for readability across devices
- **Accessibility**: Color schemes support users with color vision deficiency
- **Consistency**: Uniform spacing, radius, and typography for cohesive experience
- **Pedagogical Focus**: Component patterns derived from professional educational materials

For detailed design documentation, see [`design-system/project/README.md`](design-system/project/README.md)

## Educational Components

### Chapter Headers
Prominent section dividers with numbered circular badges containing chapter numbers. Uses dark blue background with teal accent curves and large, bold typography.

### Concept Boxes (المفردات)
Green-background boxes for vocabulary terms and concept definitions, supporting terminology learning throughout lessons.

### Example Boxes
Blue-background boxes with contextual imagery and data tables for real-world applications and practical problem-solving.

### Problem Sections
Dedicated sections with red headers for exercises, practice problems, and skill-building activities with consistent spacing.

### Vocabulary Callouts
Inline green highlights for new terminology with supporting definitions in light green boxes.

### Data Tables
Professional tables for presenting mathematical data with clear headers, alternating row styling, and high-contrast text.

## Technical Specifications

- **Typography System**: System fonts optimized for performance and accessibility
- **Spacing Scale**: 11-value scale (6px–32px) for consistent hierarchical alignment
- **Border Radius**: 5-value scale (6px–50%) for visual consistency
- **Accessibility**: WCAG-compliant color contrasts, no red/green-only differentiation
- **Language Support**: Arabic (RTL) and English (LTR) ready
